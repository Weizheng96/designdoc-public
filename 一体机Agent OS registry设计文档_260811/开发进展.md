## 1. 本次需求变更待做

对应 [需求变更.md](./需求变更.md)。变更 1（鉴权 → mTLS）**已实现**，不再列。

### 1.1 移除心跳、改 gateway 轮询元戎（变更 2）

- **删**：`heartbeat/` 模块、`POST /api/nodes/{node}/heartbeat`、`GET/POST /api/lease-config`、`NodeHeartbeatSweeper` / 租约表 / `InstanceService.expire_node` 及派生逻辑。
- **加**：存活改由 gateway 据元戎 List（[yuanrong#358](https://gitcode.com/openeuler/yuanrong/issues/358)）经 `PATCH` 写 `status`（gateway 侧，不在本仓）。
- **当前**：心跳模块仍在（默认关闭 `NodeLeaseConfig.enabled=False`），`status` 仍为查询派生。

### 1.2 status 落库可改 + 用户手动删（变更 3）

- `instance` 表加 `status` 列（`运行` / `停止` / `异常`，默认 `运行`），去掉据心跳派生。
- `PATCH /api/instances/{id}` 支持 `status`；`UpdateInstanceRequest` 加 `status`。
- 实例删除发起方 gateway → **用户**（`DELETE` 语义不变，仅调用方变）。
- `GET /api/instances` 的 `include_unhealthy=false` 下推由 `node NOT IN(…)` 改为 `status='运行'`。
- **当前**：`status` 无列、派生自心跳；`PATCH` 只 `node` / `address`。

### 1.3 ETCD 兼容（潜在·未定）

抽 `TableRepo` 接口 + `EtcdTableRepo`，按 `A2X_REGISTRY_DB_KIND` 选后端。详见 [ETCD兼容分析.md](./ETCD兼容分析.md)。**未开工。**

## 2. 其余未实现

（与本次变更无关、仍待做）

- **2.1 `registry.env` 配置文件**：代码只读进程环境变量，无读文件逻辑；agentos 当前用 systemd drop-in 注入 env。待改 `EnvironmentFile=` + `ConditionPathExists`。
- **2.2 服务注册表未进 rqlite**：`service` 表已建，但通用服务 CRUD 仍走文件（`register/store.py` 的 `RegistryStore`）；只有 image / instance 真正落 rqlite。
- **2.3 注册中心主备（跟随 rqlite 选主）**：完全未实现——无查 leader / 角色切换 / 备返 `503` 逻辑。**故多机形态不可用，只能单节点。**
- **2.4 nginx 入口与 upstream 改写**：代码 / 脚本均无。
- **2.5 HA 接口 `/api/ha/*`**：`GET /api/ha/leader`、`GET/POST /api/ha/members` 路由不存在。
- **2.6 `A2X_REGISTRY_HA_MEMBERS`**：非空即拒启动（`ValueError`）；成员奇偶校验未实现。
- **2.7 多机 rqlite 组集群部署**：`module.sh` 只用 rqlite 默认单节点配置；多机需 Raft 绑业务网卡 + 互 `join` + 4002 防火墙白名单 / 节点间 TLS。
- **2.8 客户端 SDK 一体机接口封装**：`client/a2x_registry_client/` 无 `/api/images`、`/api/instances` 方法，gateway 自拼 HTTP。
- **2.9 镜像仓文件删除**：`ImageService._delete_repo_image()` 是 stub，注销镜像只删条目、不删仓文件，响应 `repo_deleted` 恒 `false`。

## 3. 实现与契约差异

代码行为与 [`registry_openapi.yaml`](./registry_openapi.yaml) 不一致处：

| # | 位置 | 差异 |
|---|------|------|
| 1 | `POST /api/images` 响应 | 实现多返回 `is_default`；yaml `ImageOpResponse` 无此字段 |
| 2 | `DELETE /api/images/{fw}/{ver}` 响应 | 实现多返回 `repo_deleted`（恒 `false`，见 [2.9](#2-其余未实现)）；yaml 无此字段 |
| 3 | **`DB_KIND` 默认不一致** | `backend/__main__.py` 空值默认 `sqlite`，但 `backend/startup.py::_resolve_db_config()` 空值默认 **`memory`** → 不设该 env 时跑内存库、进程退出丢数据。agentos 显式设 `rqlite`，一体机不受影响；本地起服务易踩 |
| 4 | 仓内 README | `README_forAgentTeam.md` / `README_forDistributed.md` 仍写 `--host 0.0.0.0`，但 CLI 已移除 `--host`，监听改由 `A2X_REGISTRY_BIND` 决定 |

## 4. 已知风险

- **主备未实现 → 多机不可用**：只能单节点部署一个注册中心实例（`agent-gateway` 模块当前行为即如此）。原"心跳租约多机互删"风险随[心跳移除](#11-移除心跳改-gateway-轮询元戎变更-2)消失。
- **未配 mTLS 时 4003 裸 http**：mTLS 是"配了才开"；一体机若未配证书，4003 绑业务网卡等于 LAN 内可匿名调镜像 / 实例接口。须部署时配证书（[§3.3.4](./一体机Agent%20OS%20registry设计文档.md#334-端口与安全)）或以防火墙兜底。
