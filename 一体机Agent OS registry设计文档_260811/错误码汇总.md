# 错误码汇总

> 来源：同目录 [`registry_openapi.yaml`](./registry_openapi.yaml)。本文只列 **实际在接口 `responses` 中定义** 的错误码；契约以 yaml 为准。

## 1. HTTP 错误状态码

| 状态码 | 含义 | 错误体 schema | 复用响应 |
|:--:|---|---|---|
| **400** | 校验失败 | `Error` `{ detail }` | `BadRequest` |
| **404** | 资源不存在 | `Error` `{ detail }` | `NotFound` |
| **409** | 镜像仍有在用实例，拒绝注销 | `ImageInUseError` `{ code, detail, instances[] }` | `ImageInUse` |

## 2. 各接口挂载的错误码

| 接口 | 400 | 404 | 409 |
|---|:--:|:--:|:--:|
| `POST /api/images` 注册镜像 | ✅ | | |
| `PUT /api/images/{framework}/default` 设默认版本 | | ✅ | |
| `GET /api/images/{framework}/launch-spec` 取运行规格 | | ✅ | |
| `DELETE /api/images/{framework}/{version}` 注销镜像 | | ✅ | ✅ |
| `POST /api/instances` 注册实例 | ✅ | | |
| `PATCH /api/instances/{service_id}` 变更 / 状态更新 | | ✅ | |
| `GET /api/images`、`GET /api/instances`、`DELETE /api/instances/{service_id}`、`GET/POST /api/ha/*` | 仅 200，无错误响应 | | |

## 3. 业务错误码（错误体 `code` 字段）

| `code` | 触发 | 错误体 schema | 附加字段 |
|---|---|---|---|
| `image_in_use` | 409：注销镜像时仍有实例在用 | `ImageInUseError` | `instances[]`（占用该镜像的实例列表） |

- `Error`（400 / 404 用）**无 `code` 字段**，仅 `detail` 自由文本描述——即 400 / 404 不区分子类型。
- 全文业务错误码仅此一个。

## 4. 错误体 schema

```yaml
Error:                       # 400 / 404
  detail: string

ImageInUseError:             # 409
  code:      string          # 固定值 "image_in_use"
  detail:    string
  instances: string[]        # 仍在用的实例 service_id 列表
```

---

> **说明**：yaml 头部「统一约定」还提到 **403 越权**、**502 外部依赖（元戎）失败**，但二者未在任何接口定义、也无对应 schema——按现设计（mTLS + 不做 RBAC；注册中心不调元戎）实际用不上，故不计入本表。
