# 错误码汇总

> 来源：同目录 [`registry_openapi.yaml`](./registry_openapi.yaml)。本文只列 **实际在接口 `responses` 中定义** 的错误码；契约以 yaml 为准。

## 1. HTTP 错误状态码

| 状态码 | 含义 | 错误体 schema | 复用响应 |
|:--:|---|---|---|
| **400** | 校验失败 | `Error` `{ code?, detail }` | `BadRequest` |
| **404** | 资源不存在 | `Error` `{ code?, detail }` | `NotFound` |
| **409** | 镜像仍有在用实例（注销被拒）**或** 同 service_id 有在途创建/删除（模式 B） | `ImageInUseError` / `Error` | `ImageInUse` / `InProgress` |
| **501** | 模式 B 请求但未配置元戎连接 | `Error` | `RuntimeNotConfigured` |
| **502** | 元戎创建 / 删除失败（外部依赖） | `Error` | `YuanrongFailed` |
| **504** | 元戎创建 / 删除超时 | `Error` | `YuanrongTimeout` |

## 2. 各接口挂载的错误码

| 接口 | 400 | 404 | 409 | 501 | 502 | 504 |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| `POST /api/images` 注册镜像 | ✅ | | | | | |
| `PUT /api/images/{name}/default` 设默认版本 | | ✅ | | | | |
| `GET /api/images/{name}/launch-spec` 取运行规格 | | ✅ | | | | |
| `PATCH /api/images/{name}/{version}` 更新字段 | ✅ | ✅ | | | | |
| `DELETE /api/images/{name}/{version}` 注销镜像 | | ✅ | ✅ image_in_use | | | |
| `POST /api/instances` 创建/注册实例 | ✅ | | ✅ in_progress | ✅ | ✅ | ✅ |
| `DELETE /api/instances/{service_id}` 删除实例（含 ALL） | | | ✅ in_progress | ✅ | ✅ | ✅ |
| `PATCH /api/instances/{service_id}` 变更 / 状态更新 | | ✅ | | | | |
| `GET /api/images`、`GET /api/instances`、`GET/POST /api/ha/*` | 仅 200，无错误响应 | | | | | |

> 501/502/504 仅**模式 B**（registry 调元戎）才可能出现；模式 A（仅条目）不涉及。

## 3. 业务错误码（错误体 `code` 字段）

| `code` | 状态码 | 触发 | 错误体 schema |
|---|:--:|---|---|
| `image_in_use` | 409 | 注销镜像时仍有实例在用 | `ImageInUseError`（附 `instances[]`） |
| `in_progress` | 409 | 同 `service_id` 有在途创建 / 删除 | `Error` |
| `runtime_not_configured` | 501 | 模式 B 但未配元戎连接 | `Error` |
| `yuanrong_failed` | 502 | 元戎创建 / 删除失败 | `Error` |
| `yuanrong_timeout` | 504 | 元戎创建 / 删除超时 | `Error` |

`Error` 的 `code` 字段**可空**：镜像侧 400/404 通常只给 `detail`；实例模式 B 的错误带 `code`。

## 4. 错误体 schema

```yaml
Error:                       # 400 / 404 / 409(in_progress) / 501 / 502 / 504
  code:      string          # 可空；in_progress / runtime_not_configured / yuanrong_failed / yuanrong_timeout
  detail:    string

ImageInUseError:             # 409(image_in_use)
  code:      string          # 固定值 "image_in_use"
  detail:    string
  instances: string[]        # 仍在用的实例 service_id 列表
```

---

> **说明**：yaml 头部「统一约定」曾提到 **403 越权**，但未在任何接口定义（mTLS + 不做 RBAC，实际用不上），故不计入。**502 现已启用**——注册中心模式 B 直连元戎，元戎失败即映射 502（另有 501 未配置、504 超时）。
